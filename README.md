# LegalChat — хажуудаа чаттай эрх зүйн лавлах вэб

Зүүн талд дэлгэрэнгүй мэдээллийн самбар, баруун талд чат. Чатны хариултад
гарч ирэх **линк** дээр дарвал холбогдох хуулийн зүйл, заалт зүүн талд
бүрэн эхээрээ нээгдэнэ.

> ⚠ Агуулга нь **демо зориулалттай жишээ өгөгдөл**, албан ёсны хуулийн эх
> бичвэр биш. Хууль зүйн зөвлөгөө болохгүй.

## Шаардлага

Python 3.8+ — **өөр ямар ч сан суулгах шаардлагагүй** (зөвхөн стандарт сан).

## Ажиллуулах

```powershell
python app.py
```

Хөтөч автоматаар http://127.0.0.1:8000 хаяг дээр нээгдэнэ.

```powershell
python app.py --port 9000      # өөр порт
python app.py --no-browser     # хөтөч автоматаар нээхгүй
```

Зогсоох: `Ctrl+C`

## Бүтэц

| Файл | Үүрэг |
|---|---|
| `app.py` | HTTP сервер, маршрут (`http.server`) |
| `search.py` | Түлхүүр үгийн хайлт, чатны хариулт бүрдүүлэх |
| `data.py` | Жишээ эрх зүйн мэдээллийн сан (10 зүйл, заалт) |
| `static/index.html` | Хуудасны бүтэц |
| `static/style.css` | Загвар (light/dark автоматаар) |
| `static/app.js` | Чат, линк дарах, дэлгэрэнгүй харуулах логик |

## API

| Метод | Зам | Тайлбар |
|---|---|---|
| `POST` | `/api/chat` | `{"question": "..."}` → `{text, sources[]}` |
| `GET` | `/api/doc/<id>` | Нэг зүйл, заалтын бүрэн мэдээлэл |
| `GET` | `/api/suggestions` | Санал болгох асуултууд |

Чатны `text` дотор `[[doc-id]]` хэлбэрийн орлуулагч байх бөгөөд frontend
үүнийг дарж болох линк болгон хөрвүүлдэг (`static/app.js`,
`renderAnswerText`). Линк дарахад `/api/doc/<id>` руу хүсэлт явж, зүүн
самбар шинэчлэгдэнэ. Хаяг нь `#doc/<id>` болж өөрчлөгддөг тул тухайн
заалтын холбоосыг хуваалцах боломжтой.

## Цааш хөгжүүлэх

- **Жинхэнэ өгөгдөл**: `data.py`-г legal.mn зэрэг эх сурвалжаас татсан
  өгөгдлөөр солино. Бүтэц (`id, law, article, title, summary, body, tags,
  related`) хэвээр байвал бусад код өөрчлөгдөхгүй.
- **Ухаалаг хайлт**: `search.py`-н түлхүүр үгийн аргыг embedding/vector
  search-ээр солино.
- **LLM хариулт**: `search.answer()` дотор олдсон эх сурвалжуудыг Claude API
  руу дамжуулж хураангуй хариулт үүсгэнэ. Эх сурвалжийн `[[id]]` линкийг
  моделоор эшлэл болгон оруулуулна.
- **Бүтээмжийн орчин**: FastAPI + uvicorn руу шилжүүлэх (маршрутууд ижил).
