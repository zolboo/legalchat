# LegalChat — хажуудаа чаттай эрх зүйн лавлах вэб

Баруун талд чат, зүүн талд дэлгэрэнгүй мэдээлэл. Чатыг **локал эрх зүйн
агент** ажиллуулна (`../local-llm-assistant/agent`): асуултыг индексээс
hybrid аргаар (BM25 + `bge-m3` вектор) хайж, олсон заалтууд дээр
тулгуурлан `gemma3:12b` эшлэлтэй хариулт бичнэ. Олдсон материал зүүн талд
шууд жагсаагдах бөгөөд аль нэгийг дарвал **legalinfo.mn-ээс татсан бүтэн
эх бичвэр**, тухайн актын бусад заалт, утгаараа ойролцоо материалууд
нээгдэнэ.

Бүх зүйл таны компьютер дээр ажиллана — гадагш өгөгдөл явахгүй, төлбөргүй.

## Шаардлага

| Юу | Яагаад |
|---|---|
| `local-llm-assistant/agent` + үүсгэсэн индекс (`agent/index/`) | эрэл, эх бичвэр |
| Ollama дээр `bge-m3`, `gemma3:12b` | векторжуулалт, хариулт үүсгэлт |
| `numpy`, `requests` (агентын `.venv` дотор) | индекс ачаалах, Ollama клиент |

Индекс байхгүй бол эхлээд агент талдаа үүсгэнэ:

```bash
cd ../local-llm-assistant
.venv/bin/python agent/build_index.py
```

## Ажиллуулах

Агентын виртуал орчны Python-оор ажиллуулна (numpy тэнд байгаа):

```bash
../local-llm-assistant/.venv/bin/python app.py
```

Хөтөч автоматаар http://127.0.0.1:8000 хаяг дээр нээгдэнэ.

```bash
python app.py --port 9000        # өөр порт
python app.py --no-browser       # хөтөч автоматаар нээхгүй
python app.py --sources-only     # LLM ажиллуулахгүй — зөвхөн хайлт (1 секунд)
python app.py --model gemma3:4b  # өөр модел (хурдан)
python app.py --top-k 2          # контекст багасгах → хариулт хурдасна
python app.py --demo             # агентгүйгээр, жишээ өгөгдлөөр интерфейс үзэх
```

Зогсоох: `Ctrl+C`

> **CPU дээр нэг бүтэн хариулт 2-4 минут** болно. Тиймээс интерфейс
> **эх сурвалжийг эхний секундэд** зүүн талд гаргаад, хариултын текстийг
> токен тус бүрээр урсгалаар нэмнэ. Хүлээх сонирхолгүй бол `--sources-only`
> горим шуурхай ажиллана.

Агент ачаалагдахгүй бол (индекс үүсээгүй, numpy байхгүй г.м) сервер
автоматаар жишээ өгөгдөл рүү шилжинэ — интерфейс ажилласан хэвээр байна.
Ollama-г дараа асаасан ч сервер өөрөө мэдэж, хариулт үүсгэх горимд шилжинэ.

## Бүтэц

| Файл | Үүрэг |
|---|---|
| `app.py` | HTTP сервер, маршрут, SSE урсгал (`http.server`) |
| `agentchat.py` | **Агентыг холбох давхарга** — эрэл, эшлэл, холбогдох материал |
| `search.py`, `data.py` | Жишээ өгөгдлийн нөөц горим (`--demo`) |
| `static/index.html` | Хуудасны бүтэц |
| `static/style.css` | Загвар (light/dark автоматаар) |
| `static/app.js` | Чат, урсгал хүлээн авах, дэлгэрэнгүй самбар |

## API

| Метод | Зам | Тайлбар |
|---|---|---|
| `GET` | `/api/status` | Горим, модел, индексийн хэмжээ |
| `GET` | `/api/suggestions` | Санал болгох асуултууд |
| `GET` | `/api/doc/<id>` | Заалтын бүтэн эх бичвэр + холбогдох материал |
| `POST` | `/api/chat` | `{"question": "..."}` → `{text, sources[]}` (бүтнээр нь хүлээнэ) |
| `POST` | `/api/chat/stream` | Мөн адил, гэхдээ **SSE урсгалаар** |
| `POST` | `/api/clear` | Чатны түүхийг цэвэрлэх |

`/api/chat/stream` нь дараах үйл явдлуудыг илгээнэ:

```
event: sources   → {sources: [...]}   эрэл дуусмагц (~1 сек)
event: delta     → {text: "..."}      токен бүрээр
event: done      → {text, sources, elapsed}
event: error     → {error: "..."}
```

Хариултын эцсийн `text` дотор агентын бичсэн `[1]` эшлэлүүд `[[doc-id]]`
болж хөрвүүлэгдсэн байна. Frontend үүнийг дарж болох жижиг эшлэл болгон
зурдаг (`static/app.js`, `renderAnswerText`). Дарахад `/api/doc/<id>` руу
хүсэлт явж, зүүн самбар нээгдэнэ. Хаяг нь `#doc/<id>` болж өөрчлөгддөг тул
тухайн заалтын холбоосыг хуваалцаж болно.

## Хэрхэн ажилладаг вэ

```
Асуулт
  │
  ├─► BM25 түлхүүр үгийн хайлт ──┐
  │   (монгол нөхцөл ховхолсон)  ├─► RRF ─► шилдэг 4 хэсэг ─┬─► зүүн самбар (шууд)
  ├─► bge-m3 вектор хайлт ───────┘                          │
  │                                                         └─► gemma3:12b
  └──────────────────────────────────────────────────────────► эшлэлтэй хариулт [1][2]
```

Зүүн самбарт заалт нээхэд:

* **бүтэн эх бичвэр** — индексэд хадгалсан хэсэг бүтнээрээ;
* **энэ актын бусад хэсэг** — зүйл, бүлгээр нь шилжиж унших;
* **холбогдох материал** — вектор ойролцоо байдлаар өөр актаас олсон
  (акт тус бүрээс нэг заалт);
* **legalinfo.mn холбоос** — албан ёсны эх сурвалжтай тулгах.

## Анхаарах зүйл

- Агент **зөвхөн индекст байгаа эх сурвалжид** тулгуурлан хариулна. Одоогийн
  индекс нь ангилал тус бүрээс 10 акт татсан **хэсэгчилсэн цуглуулга**
  (146 акт / 1469 хэсэг) тул сэдвийн хамрах хүрээ хязгаарлагдмал. Бүрэн
  болгох: `python3 scraper/legalinfo.py` → `agent/build_index.py` дахин.
- Хариултыг эх сурвалжтай нь тулгаж шалгах хэрэгтэй — эшлэл бүрт `.txt`
  файл болон legalinfo.mn холбоос хавсаргагдсан.
- Энэ бол лавлагааны хэрэгсэл болохоос хууль зүйн зөвлөгөө биш.
